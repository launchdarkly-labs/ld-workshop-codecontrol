Three labs in, the Personalized strategy has shipped, failed, been seen, and been reverted. The pieces so far:

- The **server plugin** turned every request into a trace carrying the flag evaluations made during it, and recorded any exception that escaped.
- The **browser plugins** recorded errors and a **session replay** of what the shopper saw.
- The flag's **Monitoring** tab grouped errors, logs, and sessions **by variation**, which is what made the `KeyError` obviously Personalized's fault.
- **Autogenerated metrics** like **User HTTP error rate** turned that into a number LaunchDarkly can compare across variations, with *lower is better* already set.

# One question

On the **Monitoring** tab, every `KeyError: 'category'` sat under **Personalized** and none under **Bestsellers**. How did LaunchDarkly know which variation each error belonged to?
