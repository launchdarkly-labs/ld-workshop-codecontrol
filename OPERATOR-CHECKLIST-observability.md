- [ ] **Live-fire end-to-end smoke test** against a fresh sandbox: bootstrap → materialize the post-Release baseline → click through every challenge → solve every challenge → confirm every check passes. Time each challenge.
- [ ] **Track-level `setup-workstation` timing** — it bootstraps, mints the token, **and applies Release's solve modules** to reach the baseline. If this pushes startup past ~60s, decide with the operator whether to pre-bake the post-Release state into the VM image.
- [ ] **Confirm the baseline** a cold learner lands in: Otto shipped and rolled out, SDKs wired, the recommendations carousel present, the personalized-strategy bug intact (not accidentally fixed).

- [ ] **VM image re-bake** picks up `launchdarkly-observability` in the venv, the two vendored browser plugin bundles, the `instruqt-*/` directories (the Observability setup calls Release solve scripts from `/opt/ld/codecontrol/instruqt-release/`), and the traffic unit's `EnvironmentFile=-/opt/ld/traffic.env`.

Confirm the error volume on Personalized is visible within a minute and not so high the storefront log is unreadable; tune `terraform/lib/traffic.sh` if needed.
